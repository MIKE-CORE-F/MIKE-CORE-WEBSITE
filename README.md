## 🚀 Deployment Instructions
Because this repository utilizes a root-level index layout, it is instantly compatible with automated static hosting:
1. Navigate to your repository **Settings** on GitHub.
2. Select **Pages** from the sidebar menu.
3. Under Build and deployment, verify the source is set to **Deploy from a branch**.
4. Choose the `main` branch and ensure the directory folder path is set to `/ (root)`.
5. Click **Save** to deploy the document repository to your public live domain.
